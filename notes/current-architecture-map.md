## Backend selection

`src/handler.rs:21-26` (mock wins over everything):

```rust
#[cfg(all(target_os = "android", not(any(test, feature = "mock"))))]
use crate::android::{Adapter, Manager, Peripheral};
#[cfg(any(test, feature = "mock"))]
use crate::mock::{Adapter, Manager, Peripheral};
#[cfg(not(any(target_os = "android", test, feature = "mock")))]
use btleplug::platform::{Adapter, Manager, Peripheral};
```

Other cfg sites: `models.rs:55-56` (blanket `BondingPeripheral` off-android), `models.rs:62-65`
(`target_vendor = "apple"` uses `id()` as address), `models.rs:84-87` (`is_bonded` only on android),
`commands.rs:285-296` (`set_android_mtu` no-op off android), `handler.rs:131-134`
(`Handler::set_android_mtu_request(mtu)`, associated fn), `error.rs:46`.

btleplug is compiled on Android but only for its `api` traits/types; `btleplug::platform::init` is
never called, so no droidplug Java is in the APK.

## Tauri IPC (commands.rs)

No `app.emit` anywhere; every stream is a `tauri::ipc::Channel<T>` command argument:
`scan(timeout, on_devices: Channel<Vec<BleDevice>>, allow_ibeacons)` 12-33,
`connect(address, on_disconnect: Channel<()>, allow_ibeacons)` 44-65,
`connection_state(update: Channel<bool>)` 76, `scanning_state(update: Channel<bool>)` 99,
`subscribe(.., on_data: Channel<Vec<u8>>)` 185 / `subscribe_string(.., Channel<String>)` 203,
`check_permissions` 233 (sync), `set_android_mtu` 287. `guest-js/index.ts` mirrors with `new Channel()`.

## Rust ↔ Kotlin protocol (android.rs ↔ android/src/main/java)

Registration: `android.rs:47` `api.register_android_plugin("com.plugin.blec", "BleClientPlugin")`,
stored in `static HANDLE: OnceCell<PluginHandle<Wry>>`. Calls are blocking; async ones go through
`call_plugin_with_timeout` (android.rs:678): `spawn_blocking` + `tokio::time::timeout(op_timeout + 5s)`.

### Kotlin → Rust callbacks (all via `Channel.send(JSObject)`, no `trigger`)

1. Scan results: `BleClient.kt:188` `{result: device}` → `on_device_callback` (android.rs:62) upserts
   `DEVICES: Lazy<RwLock<HashMap<PeripheralId, Peripheral>>>`. Device JSON (`BleClient.kt:52-92`):
   `address, id, name, connected, bonded, rssi, txPowerLevel, services[], manufacturerData{u16→base64}, serviceData{uuid→base64}`.
   Rust `Peripheral` (android.rs:289) deserializes `id, address, name, rssi, manufacturerData, serviceData, services, txPowerLevel`; `mtu_val` defaults to 23.
2. Central events: `Peripheral.kt:133-146` `{"DeviceConnected": mac}` / `{"DeviceDisconnected": mac}`
   on `plugin.eventChannel` → deserialized directly into `btleplug::api::CentralEvent`.
3. Diagnostic: `Peripheral.kt:160-183` `{"LinkStillConnected": mac}` after 1500 ms grace → Rust logs a warning only (android.rs:116).
4. Notifications: `Peripheral.kt:292-305` `{uuid, serviceUuid, data: base64}` on the per-device
   `notifyChannel` → `ValueNotification` stream (android.rs:613).

### Kotlin structure

- `BleClientPlugin.kt`: `class BleClientPlugin(activity: Activity): Plugin(activity)`, `@TauriPlugin`
  permission aliases `bluetooth` (`BLUETOOTH_SCAN`+`BLUETOOTH_CONNECT`), `bluetoothLegacy`
  (`BLUETOOTH_ADMIN`+`BLUETOOTH`), `location` (`ACCESS_FINE_LOCATION`). Maps `devices` (scanned) and
  `connected_devices`. Arg classes: `ConnectParams`, `NotifyParams{address, channel}`,
  `WriteParams{address, characteristic: UUID?, service: UUID?, data: ByteArray?, withResponse, timeout: Int, skipWaitingForWriteToComplete}`,
  `ReadParams`, `CheckPermissionsParams{allowIbeacons, askIfDenied}`, `MtuParams{address, mtu=517}`,
  `BleClient.ScanParams{services: ArrayList<String>, onDevice: Channel?, allowIbeacons}`.
  Permission flow 266-318: `hasBTPermissions()` picks alias by `SDK_INT >= S`; `check_permissions`
  → `requestPermissionForAliases(..., "permissionsCallback")`; callback re-checks, and when still
  denied with `askIfDenied` opens `Settings.ACTION_APPLICATION_DETAILS_SETTINGS` + Toast.
- `BleClient.kt`: scanner (`ScanCallback`), `retrievePeripheral` via `BluetoothAdapter.getRemoteDevice`,
  `adapterState`, `toJsObject`. Uses `activity` for `getSystemService`, `getSharedPreferences`,
  `ActivityCompat.startActivityForResult(enableBtIntent)` (line 130), `Peripheral(activity, device, plugin)`.
- `Peripheral.kt`: `BluetoothGattCallback` (188-465), `runOnMain` 101, `isTransientStatus` 78,
  `connect`/`connectInternal` 467/482 (`device.connectGatt(activity, false, callback, TRANSPORT_LE)` 513),
  `discoverServices` 523, `disconnect(invoke, onComplete)` 565, `failPendingWrites/Operations` 625/645,
  `services` 706, `write` 737 + `processWriteQueue` 779 (queue, `callbackWaitMs`, `isWriteTimedOut`,
  `discardTimedOutQueuedWrites`), `read`/`startRead` 986/998, `subscribe`/`startDescriptorWrite` 1032/1062,
  `requestMtu` 1110, `statusCodeName` 1129. Pending-op holders: `onReadInvoke`, `onDescriptorInvoke`, `onMtuInvoke`.
  Uses `activity` only as a `Context` (lines 166, 513).
- Gradle: `com.android.library`, namespace `com.plugin.blec`, compileSdk 34, minSdk 26, Java 8; deps
  androidx core-ktx/appcompat/material + `project(":tauri-android")`; `settings.gradle` pins AGP 8.0.2,

## Known bugs spotted (fix during the split)

- `allowIbeacons` is never sent in `check_permissions`, so the `location` alias is never requested
  through that path even though `ALLOW_IBEACONS` and `start_scan` carry the flag.
- `Peripheral::services()` is a sync trait method doing a blocking IPC call with `.expect` (android.rs:427-435).
- `Manager/Adapter::adapter_info`, `write_descriptor`, `read_descriptor` are `todo!()` on Android.
